# ***InfraSCusPrice***
#### Développé par ***InfraS*** - Membre du programme officiel ![](img/Dolibarr_preferred_partner_small.png), gage de qualité et d’expertise.
* Le déploiement des prix client ***InfraS*** automatise le renseignement des prix des filiales :
	 * À partir d'un tiers déclaré comme maison mère d'un groupe ayant des prix clients renseignés
	 * Suite à l'ajout d'une ou plusieurs filiales
	 * Vous pouvez d'un clic affecter ces prix de vente aux nouvelles filiales
	 * Quand un tiers déclaré comme filiale d'un groupe est détaché de celui-ci, tous les prix clients précédemments renseignés peuvent être supprimé d'un seul clic.

## Ce qu'est ***InfraSCusPrice***

***InfraSCusPrice*** est un module optionnel de Dolibarr ERP & CRM pour facilité le déploiement de prix client d'une maison mère vers ces filiales.



## Déploiement / installation

* Utilisez de préférence l'outil de déploiement des modules externes



## Activation des modifications

Pour le bon fonctionnement du module ***InfraSCusPrice*** :
* Après toute mise à jour de Dolibarr et / ou du module
	* Il est IMPERATIF : De désactivez puis réactivez le module pour effectuer les modifications nécessaires de la Base de données et dans les fichiers
