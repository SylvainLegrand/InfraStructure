#### Développé par ***InfraS*** - Membre du programme officiel ![](img/Dolibarr_preferred_partner_small.png), gage de qualité et d’expertise.
* La recherche ***InfraSSearch*** apporte de nombreuses améliorations aux fonctions de base :
	* Une recherche exhaustive incluant les attributs supplémentaires (extrafields) dans tous les types d'éléments disponibles
	* Une page dédiée à la présentation des résultats
	* Des liens directs vers l'élément sélectionné quel qu’il soit.
	* Le remplacement complet de l'outil standard pour une ergonomie approfondie
	* Un fil d'Ariane paramétrable (vous choisissez le nombres d'éléments à présenter)

## Ce qu'est ***InfraSSearch***

***InfraSSearch*** est un module optionnel de Dolibarr ERP & CRM remplaçant ou complétant l'outil de recherche standard.
***InfraSSearch*** effectue une recherche exhaustive dans les éléments suivants :
* Éléments de base
	* Tags/Catégories
	* Tiers (prospects, clients, fournisseurs)
	* Adresses
	* Contacts
	* Produits / Services
	* Projets
	* Tâches
	* Évènements (agenda)
* Chaîne des ventes
	* Devis
	* Commandes client
	* Contrats
	* Factures
* Chaîne des achats
	* Devis fournisseur
	* Commandes fournisseur
	* Factures fournisseur
* GRH
	* Note de frais
* Documents techniques
	* Fiches d’intervention
	* Bons de livraison (Expéditions)
	* Articles de la base de connaissances
* Modules externes
	* Équipements (Patas-Monkey)
	* Factory (Patas-Monkey)
	* RmindR (Patas-Monkey)
	* Notes de frais + (Mikael Carlavan)
	* Suivi des contacts/échanges (Inovea)
	* Domaine (Librethic)
	* Hosting (Librethic)
	* Ticket/Support technique (Librethic)
	* Historique proposition commerciale (ATM)



## Fonctionnalités (toutes optionnelles)

* Trier les résultats (pour les documents) par ordre de date croissant ou décroissant
* Limiter les recherches à l'entité en cours (compatibilité avec le module ***“Multi-société” - iNodbox***)
* Dans la page de recherche (menu Outils) afficher le détail du champ contenant l'expression recherchée avec celle-ci en gras
* Remplacer la recherche standard dans le menu gauche
* Placer la zone de recherche sur le menu haut (à droite)
* Déclencher la recherche après la saisie d'un certain nombre de caractères minimum (optimisatio des temps de recherche)
* Paramétrer le délai d'attente pour le déclenchement de la recherche (après la saisie du nombre de caractères minimum requis)
* Limiter le nombre d'occurrences présentées comme résultat
* Activer un fil d'Ariane sur le menu haut (à droite)
	* Limiter le nombre d'éléments présentés comme résultat
* Choisir l'étendue de la recherche parmi les modules activés
* Choisir l'ordre d'affichage des résultats parmi les modules activés (par exemple, afficher les tiers avant les produits)
